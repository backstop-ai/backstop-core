# go standards pack

Enforces Go-specific coding standards, project structure conventions, and idiomatic patterns.

Checkers in this pack are written in Go.

## Contents

- `policies/` — OPA policies for Go-specific rules
- `src/` — Go AST checkers
- `bin/` — Compiled checker binaries (build output, gitignored)
- `testdata/` — Valid and invalid Go fixtures for testing
