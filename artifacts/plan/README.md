# Plan

An execution plan that breaks intent into phased tasks with claims, dependencies, and verification criteria. Plans are the bridge between specs and implementation.

## Schema

- `schema.json` — JSON Schema for plan validation
- `template.md` — Markdown template for new plans

## Versioning

Schemas are versioned in subdirectories (e.g., `v1/`). The root `schema.json` always points to the latest stable version.
