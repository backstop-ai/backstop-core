# Implementation Spec

Defines an implementation plan derived from an ADR or user intent. Includes claims that must be verified before the spec is considered complete.

## Schema

- `schema.json` — JSON Schema for spec validation
- `template.md` — Markdown template for new specs

## Versioning

Schemas are versioned in subdirectories (e.g., `v1/`). The root `schema.json` always points to the latest stable version.
