# Issue

A lightweight artifact for bug fixes and small features. Generated on-the-fly during development rather than through formal spec authoring.

## Schema

- `schema.json` — JSON Schema for issue validation
- `template.md` — Markdown template for new issues

## Versioning

Schemas are versioned in subdirectories (e.g., `v1/`). The root `schema.json` always points to the latest stable version.
